# Support

EvidenceVeil is an open-source project maintained on a best-effort basis.

## Community support

Use GitHub Issues for:

- non-sensitive defects
- reproducible behavior problems
- documentation gaps
- feature requests
- format or policy suggestions

When opening an issue, include the EvidenceVeil version, Python version, operating system, expected behavior, actual behavior, and a minimal reproduction using **synthetic data only**.

## Sensitive or security-related reports

Do **not** attach real incident evidence, customer logs, credentials, private keys, production tokens, or `.evlt` vaults to a public issue.

For suspected vulnerabilities or sensitive security concerns, follow [SECURITY.md](SECURITY.md).
