# Transformation Reference

EvidenceVeil supports `keep`, `drop`, `redact`, `mask`, `tokenize`, `pseudonymize`, `generalize`, `bucket`, `shift`, `truncate`, `replace`, `synthesize`, `hmac`, `preserve`, and `quarantine`. Predictable identifiers use keyed HMAC-derived tokens rather than unkeyed hashes. Timestamps can use a dataset-wide shift so ordering and deltas remain intact.
