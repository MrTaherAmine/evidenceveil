# EvidenceVeil v1.0.0 — Initial Production Release

**Share incident data without exposing the incident.**

EvidenceVeil v1.0.0 is the first production release of a local-first privacy-engineering toolkit for cybersecurity telemetry and incident-response evidence. It is designed for situations where teams need to share useful evidence without casually exposing identities, credentials, internal architecture, cloud identifiers, case context, or exact timelines.

## Highlights

- Offline-by-default CLI with no account, API key, hosted backend, analytics, or LLM requirement.
- Versioned policy-as-code DSL with seven built-in sharing presets.
- Deterministic, correlation-preserving pseudonymization using domain-separated keyed HMAC derivation.
- Separately encrypted reversible mapping vaults using Argon2id and ChaCha20-Poly1305 AEAD.
- Streaming processing for JSONL/NDJSON, CSV/TSV, text/logs, CEF, LEEF, and syslog-like data.
- JSON-aware handling for ECS, OCSF, OpenTelemetry Logs, and STIX 2.1.
- Gzip text import plus bounded ZIP/TAR extraction primitives; direct archive sanitization is not exposed by the v1.0 CLI. EVTX and Parquet are recognized but intentionally unsupported for parsing/sanitization in v1.0.
- Residual disclosure-risk audit with careful release statuses instead of a misleading anonymity score.
- Versioned utility-contract framework with lightweight structural checks for required-field, stable-relationship, and temporal-order requirements; deeper semantic utility validation remains future work.
- Self-contained offline HTML report, manifest, provenance records, and checksums.
- Authenticated restore workflow for reversible pseudonyms.
- GitHub Action with fixture safety checks and SARIF output.
- Trusted-code plugin SDK with a tested example plugin.
- Synthetic security fixtures, hostile-input tests, and cross-platform CI configuration.

## Privacy language

EvidenceVeil deliberately distinguishes redaction, masking, pseudonymisation, de-identification, synthetic replacement, and anonymisation. Pseudonymized data may remain personal data. The tool reduces identified disclosure risk but cannot determine legal anonymisation or guarantee that a dataset is safe to disclose.

## Install

```bash
python -m pip install evidenceveil
```

Or install from the source release/repository before PyPI publication:

```bash
python -m pip install .
```

## Quick demo

```bash
evidenceveil discover samples/enterprise-incident

evidenceveil sanitize samples/enterprise-incident \
  --policy vendor-support \
  --new-key \
  --vault ../secure-vaults/demo.evlt \
  --output demo-output \
  --report

evidenceveil verify demo-output
```

## Scope boundaries

v1.0 does not rewrite binary EVTX or PCAP, does not provide managed key escrow, does not certify anonymisation, does not sandbox plugins, and does not replace human disclosure review. See `docs/limitations.md` for the full list.
