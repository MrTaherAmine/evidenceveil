# EvidenceVeil v1.0.1 — Maintenance Release

EvidenceVeil v1.0.1 fixes a correctness defect in reversible IP pseudonymization and hardens restoration integrity.

## Fixed

- Prevented distinct public IPv4 addresses from silently converging on the same reversible pseudonym.
- Added deterministic collision resolution and fail-closed mapping guards.
- Scoped forward mappings by semantic/namespace.
- Added order-independent deterministic IP allocation during sanitization.
- Prevented cascading substitutions during restoration.
- Corrected `.tar.gz` / `.tgz` format detection ordering.

## Compatibility

The vault schema remains `fake -> real`, so non-corrupted v1.0.0 vaults remain restorable. Bundles from v1.0.0 that already suffered a collision cannot reconstruct an overwritten mapping and should be re-sanitized from the original evidence with v1.0.1.

## Validation target

Release validation includes the exact Issue #2 reproduction, a 1,000-public-IP round-trip stress test, full automated tests, static analysis, dependency audit, and wheel/sdist validation.
