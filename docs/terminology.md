# Terminology

- **Redact:** replace with a constant removal marker.
- **Mask:** preserve a limited visible portion of a value.
- **Tokenize:** replace with a stable non-secret token.
- **Pseudonymize:** consistently replace a value, optionally retaining a separately protected mapping.
- **Generalize:** replace precision with a broader category.
- **Synthesize:** create a fictitious, format-compatible value.
- **Anonymisation:** a contextual legal/risk conclusion EvidenceVeil does not make automatically.
